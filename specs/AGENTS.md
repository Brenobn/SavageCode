# Specs Playbook

Use esta pasta para definir a feature antes de implementar.

## Nome do arquivo

- Formato: `<tema>-spec.md`
- Ex.: `result-page-spec.md`

## Estrutura minima obrigatoria

1. `# Especificacao - <titulo>`
2. `## Contexto` (problema + objetivo)
3. `## Escopo` (`In scope` e `Out of scope`)
4. `## Requisitos` (funcionais e tecnicos)
5. `## Criterios de aceite` (itens verificaveis)
6. `## Plano de implementacao` (checklist)

## Regras

- Seja curto e direto; evite texto longo sem decisao.
- Liste decisoes concretas (nao deixar ambiguidade para implementacao).
- Se houver biblioteca/API envolvida, baseie a spec em docs atualizadas (Context7).
- Nao iniciar implementacao antes da spec estar clara e completa.
